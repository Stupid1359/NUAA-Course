# 讲义设计

## 文件与元数据

每个课次维护一份讲义。文首使用 YAML 记录已有可靠信息：

| 字段 | 内容 |
| --- | --- |
| `type` | `course-lecture` |
| `course` | 正式课程名称 |
| `course_id` | 已确认的课程标识，缺少时省略 |
| `lesson_id` | 字符串形式的课次标识，缺少时先确认课次身份 |
| `date` | 带引号的 `YYYY-MM-DD` |
| `leti_number` | 真实节次 |
| `teacher`、`classroom` | 仅在私有资料中按需填写；公开资料省略 |
| `source` | 本节转写或字幕文件的位置；公开资料使用相对路径 |
| `source_range` | 本节已读取资料的起止媒体时间 |

保留用户已有且有效的自定义字段。H1 使用 `课程名称｜YYYY-MM-DD 第N节`，随后注明本节主题与资料范围，直接进入教学内容。

## 正文结构

按教师的讲授顺序组织主要主题，每个主题使用独立的 H2，并在标题注明时间范围，例如 `## 带权区间调度（10:47–15:44）`。主题之间保留必要的推导和因果关系。

根据具体内容选择适用的组织方式：

| 教学内容 | 应说明的内容 |
| --- | --- |
| 概念与理论 | 定义、适用条件、关键区别、课堂例子、容易误解的条件 |
| 算法与计算 | 问题与输入输出、状态或步骤、必要公式、边界条件、推导、例子、适用时的正确性和复杂度 |
| 历史与人文 | 时间背景、人物或作品、事件与论点、教师给出的依据、课堂分析过程 |
| 案例与作品分析 | 案例名称、观察角度、具体证据、论证过程、教师的结论 |

主要主题内的重要定义、例子、推导转折和教师强调处附上更具体的时间点或范围。正文应能够支持独立理解课堂内容；篇幅随真实内容决定。

数学使用 LaTeX。代码标识符保留英文原名。板书或幻灯片未被转写记录的数字、代码及图示内容需要额外证据；资料不足的部分明确标注待核实。为理解补充的推导标注“补充说明”，并核对其成立条件。教师表述中的条件与确定程度应完整保留。

## 时间戳

- 每个主要主题都给出对应的源资料时间范围。重要知识点可以用 `（12:31–12:59）` 这样的形式进一步定位。
- 时间范围依据实际字幕条目确定，起点早于或等于终点，终点处于可引用资料范围内。使用 `mm:ss`，超过一小时使用 `hh:mm:ss`。
- 一个主题在不连续的位置出现时分别标注多个区间，例如 `（12:31–12:59；15:05–15:44）`。
- 课堂日期、排定的上课时长与媒体时间分别使用；主题时间不能按篇幅或平均课时估算。
- 只有文字内容而没有可靠时间信息时，该课次暂不生成符合本设计的讲义。说明缺失资料，等待可靠时间信息或用户明确调整要求。
- 原话的时间范围按照实际引用的字幕条目填写；相邻条目可以分别引用，省略了中间内容时使用独立引文。

## 重点标注

使用加粗文字和明确标签，控制在真正需要关注的内容上：

| 标签 | 使用依据 |
| --- | --- |
| `**【教师强调】内容**` | 教师明确要求注意、记住、掌握，或反复强调的内容；附时间 |
| `**【考试要求】内容**` | 教师明确联系考试、题型、范围或答题要求；附时间，末尾保留原话 |
| `**【理解重点】内容**` | 为理解本节所必需的概念、条件或推导；表示讲义编写者的教学判断 |

“如果考到”“可能会考”“这次不考”等限制必须完整保留。“考试要求”也可以记录明确排除的范围。仅凭教师重复讲解或知识本身重要，无法确定考试范围。

## 每节课的最后一个主要章节

最后一个 H2 固定为 `## 考试、作业与成绩事项`，包含 `### 考试与成绩` 和 `### 作业`。本章节之后结束讲义。

每条事项使用以下形式，完整规则见 [事项记录](assessment-records.md)：

1. **事项名称及现行要求。** 写明条件、适用范围和必要操作。
2. **时间。** 对应字幕或录制片段中的真实区间。
3. **原话。** 使用 Markdown 引用块逐字保留字幕文字；说明“原话按字幕记录”。公开资料中含个人信息的引文按[事项记录](assessment-records.md)省略正文，保留来源时间。
4. **关键限制。** 成绩比例、截止要求、提交方式、考试范围等按来源填写，未说明的信息写“未说明”。
5. **课程记录。** 给出稳定事项标识及对应 `作业.md` 或 `考试.md` 的相对链接。

全文已完整读取且某类事项没有明确记录时，写“本节可用资料中未发现明确的考试与成绩事项”或“本节可用资料中未发现明确的作业事项”。存在资料缺口时，应当说明覆盖范围及尚未核实的部分。

一条通知同时涉及作业与成绩时，两类记录通过同一事项标识或交叉引用保持联系，完整引文在本节末尾保留一份即可。

## 检查方法

逐个主要主题核对其内容与来源区间。逐条核对末尾事项的原话、时间、数字及限制词；再检查它们与课程事项文件的对应关系。检查相对链接和元数据是否指向当前课程及课次。任何重点标签都应当能够说明使用依据。
