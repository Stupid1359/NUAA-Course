# 章节索引

## 维护目标

在每门课程的 `复习/章节索引.md` 中维护章节与课堂位置的对应关系，让用户能够查到某一章从哪节课的什么时间开始，到哪节课的什么位置结束，以及中间涉及哪些课次。索引随着讲义新增或更新持续维护。

每章保留主要教学范围。有可靠小节名称，或内容跨度需要进一步定位时，增加一层小节；相邻的同一主题合并记录。定义、单个例题和短暂插话通常保留在讲义中。

## 章节依据与课次身份

- 优先采用教师明确介绍的章节、课堂课件目录或用户指定的课程大纲。教材章节只有在教师明确采用该教材结构时才作为课程章节依据。
- 章节名称与编号需要来源支持。只有主题信息时，按主题名称暂列，并注明“章节归属待确认”；不得凭授课顺序编造正式章节编号。
- 教师只说“这一章”时，可以结合相邻已核实课次和课件确认章节；信息不足时保留待确认状态。
- 每个课次使用日期、实际节次和 `lesson_id` 定位。metadata 中的 `letiNumber` 表示当天的节次；全课程第几次课只有在完整课次清单已经确认时才能附加，日期和实际节次仍需保留。
- 已有讲义中的可靠时间可用于定位；遇到章节开始、结束或归属不清时，读取对应字幕上下文和必要的相邻课次核实。

## 文件结构

文首 YAML 使用 `type: course-chapter-index`、`course`，有可靠课程标识时增加 `course_id`。H1 使用 `课程名称｜章节索引`。注明已核实的课次范围、资料缺口和章节划分依据。

随后设置章节表，使用以下列：

| 列名 | 填写内容 |
| --- | --- |
| 章节 | 有依据的章号与名称，或待确认的主题名称 |
| 开始位置 | 日期、实际节次、媒体时间及来源讲义链接 |
| 结束位置 | 日期、实际节次、媒体时间及来源讲义链接 |
| 涉及课次 | 逐个列出日期与实际节次，链接到对应讲义 |
| 核实情况 | 已确认完整范围、持续讲授中、起点待确认、终点待确认或中间资料缺失 |

每章使用一个 H2。章内使用时间区间表，列为“内容”“课次”“时间范围”“讲授性质”。“课次”包含日期、实际节次、`lesson_id` 和讲义链接；“讲授性质”可记录首次讲授、继续讲授、复习回顾或补充讲解。

没有适合的小节划分时，每个课次按该章的主要内容记录一行。有适合的小节时，在“内容”列填写小节名称；同一小节跨课次时分别记录各课次区间。小节限于一层，正式小节编号同样需要依据。

## 时间范围与更新

- 每个区间使用对应课次的媒体时间，开始和结束均核对真实教学内容。跨课次的章节分别保留每节课的时间区间。
- 一节课发生章节切换时，分别记录前一章的结束位置和后一章的开始位置。使用教师的过渡语句和实际内容核实交接处，不能默认取课次开头或结尾。
- 同一章在一节课内不连续出现时，分别列出各区间。同一段综合讲解涉及多个章节时，可以分别引用，并说明共享内容。
- 后续复习回顾或补充讲解单独记录讲授性质；章表中的主要教学起止位置依据该章的正式讲授范围填写。
- 最早已读取的片段可能位于章节中间，最近已读取的课次也可能尚未讲完该章。此时写明“已核实至”或“最早已核实位置”，并标注起点或终点待确认。
- 章节中间存在未读取课次或资料缺失时，明确列出缺口；仅凭起止两端无法判定中间所有课次均讲授同一章。
- 生成或更新讲义后，按课程身份、章节或主题、`lesson_id` 和时间范围定位现有条目，补充或修正相应区间，保留用户备注与其他章节。重复处理同一课次时复用已有条目。
- 保留实际存在的相对讲义链接。索引单独维护且某课次尚无讲义时，记录课次及源资料位置；讲义建立后补充链接。

## 验收

逐章核对章表的起止位置与章内区间表是否一致，每个时间范围是否处于对应源资料范围内，链接是否能返回正确课次。检查跨课次衔接、同课多章、后续回顾及资料缺口的表达。确认每个本次已整理的主要教学主题都有章节归属或明确的待确认记录，且章号与小节名称有来源支持。
