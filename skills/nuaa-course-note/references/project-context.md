# 项目位置

## 课程目录

使用时根据当前请求确定目标课程目录。未指定位置时，以当前工作目录下的 `课程/<课程名称>` 为目标。正式课程名称优先依据当前 metadata 的 `subjName`，结合用户请求确认。同名课程的班级或学期不同且资料可能混合时，先确认本次对应的课程身份。

定位已有讲义优先使用 `lesson_id` 和课程身份，其次核对日期、节次。讲义文件名使用 `YYYY-MM-DD 第N节.md`，更新正文时保持既有文件名和有效引用。遇到同名文件对应不同课次时停止写入并核实。

用户现有课程资料可以作为阅读来源。文件迁移与重新分类按照用户明确指定的范围执行。

## 本地课堂资料

先检查用户提供的源资料位置。使用本项目时，可以通过包含 `pyproject.toml` 和 `nuaa_course/` 的目录确定源码根目录。项目的默认数据目录位于源码根目录的上一级目录下的 `data/`，课程资料通常位于 `data/courses/`。实际路径以当前配置和文件为准。

使用课程字幕程序的配置时，依据其当前 `nuaa_course/config.py` 确定数据目录和课程配置；配置中的相对源资料路径相对于数据目录解析。配置中没有该课程时，可以检查已知课程资料目录下的 `course.json`、`replay_inventory.json` 和课次 metadata，确认课程身份与实际文件。

课程目录下的 `lessons/<lesson_id>/` 通常包含：

| 文件 | 用途 |
| --- | --- |
| `metadata.json` | `id`、`teclId`、`subjName`、`courBeginTime`、`letiNumber`、教师和教室 |
| `raw/transcript.txt` | 带媒体时间的课堂转写，作为正文和引文的主要证据 |
| `raw/subtitle.json` | 核对字幕条目、原始文本和时间单位 |
| `note.md` | 已有源笔记，可用于参考和发现需要保留的内容 |

源资料路径与目标课程路径分别确定。维护讲义、事项和章节索引时，直接读取资料并编辑目标文件。章节索引固定为 `课程/<课程名称>/复习/章节索引.md`，从该文件引用讲义时使用 `../讲义/` 下的实际文件路径。

公开仓库中的 `course_materials/` 存放经隐私检查的课程副本。向公开目录新增资料时，核对学生姓名、联系方式、账号凭据和本机路径，并省略课堂点名中的姓名。原始字幕、平台响应和浏览器登录资料保存在本机数据目录。

## 时间与来源

`courBeginTime` 用于确定课次日期，课堂内容的时间戳使用该课次字幕或媒体中的时间。转写最后一条字幕的时间用于确定可引用资料的范围。

若一份资料合并多个课次，保留资料自身的时间基准，并明确每个课次对应的区间；重置时间需要可验证的起点。多个录制片段应分别标明片段名称和片段内时间。

JSON 使用标准库解析，YAML 和 Markdown 使用成熟的第三方库解析。Python 命令使用当前环境中已验证可用的解释器。
