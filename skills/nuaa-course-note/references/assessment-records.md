# 作业、考试与成绩记录

## 读取和判断证据

完整阅读每节课之后，使用以下词语复查相关位置及上下文：

- 作业、练习、报告、论文、展示、提交、上交、补交、截止、超星、学习通、平台。
- 考试、期中、期末、测验、考查、开卷、闭卷、题型、题量、范围、复习、答题。
- 成绩、学分、分数、分值、占比、比例、平时分、加分、扣分、考勤、签到、点名、出勤、课堂表现、参与。
- 下周、下节课、最后一次、每个人、每组、统一要求、记得、需要完成，以及本课程实际使用的同义表述。

检索用于复查全文阅读结果。算法中的“作业调度”、案例中的“考试”以及一般性的“重点”，都需要结合上下文判断。仅记录教师面向本课程学生的要求或考核信息。学生的询问只有在教师确认后才能作为已确定要求。

字幕已经显示教师在说明某项作业或考核，但具体要求被截断、说话人不明或文字无法可靠理解时，保留可核实的时间和原话，登记为待确认事项，并说明尚未明确的部分。已经识别出的具体要求照常记录；整节课的核实范围与资料缺口分别注明。

签到处理、补签、出勤要求等列入 `考试.md` 的考勤事项，即使具体分值尚未说明。课堂点名提问只有在提出普遍参与要求或明确关联考核时才登记。公开资料省略个别学生的姓名与可识别的回答过程。

课后自行练习也记录在 `作业.md`，类型标明“课后练习”。正式提交、截止时间和分值按教师实际表述填写。

## 引文与时间

每条证据包含课程、日期、节次、`lesson_id`、媒体时间范围和对应原话。课程文件保存来源讲义的相对 Markdown 链接；讲义元数据记录原始资料位置。

仅维护事项且对应讲义尚未建立时，直接标注原始字幕或转写文件的实际位置。讲义建立后，可以在该事项下补充讲义链接。

原话按字幕记录，逐字保留原始文字、数字、标点和语气词。相邻字幕条目可以分别使用引用块，并逐段标明时间。公开资料中的引文如包含个人信息，省略该段引文并注明来源时间。转述、语句整理和补充解释放在“要求”中。引文疑似存在字幕识别问题时，保留原文并将相关要求标为“待核实”；有可用的可靠资料时继续核对。

条件词决定结论的确定程度。“如果考试要求写递推式”记录为条件性的答题提醒；“可能采用某种形式”记录为待确定安排。没有明确的分值、比例、提交地址或截止时间时使用“未说明”。

相对时间保留原话，例如“下节课”“下周交”。仅在课次日期和课程安排足以唯一确定时间时增加对应日期，并标明推算依据；存在歧义时保持待确认。

## 两份课程文件

每门课程在 `作业&考试` 目录下维护 `作业.md` 和 `考试.md`。首次整理课程时创建两份文件，已有内容逐条更新。

两份文件的 YAML 至少包含 `course` 和 `type`；`type` 分别使用 `course-homework`、`course-assessment`，有可靠课程标识时增加 `course_id`。文首注明已核实的课次范围或课次清单，范围以实际完整读取的课次为准。

### 作业.md

每个独立事项使用一个 H2，例如 `## A-1571350-01：背包表格课后练习`。填写：

- 类型：正式作业、课后练习、报告、展示等。
- 现行要求：题目、范围、个人或小组安排、需要完成的内容。
- 提交要求：截止时间、提交平台或地点、文件格式、命名和其他明确要求。
- 成绩关联：明确提到的分值、比例、评分要求、迟交或补交规则。
- 完成情况：保留用户记录。首次出现且没有用户完成证据时写“未记录”。
- 来源证据：每次相关提及的日期、节次、时间范围、逐字原话、讲义链接。
- 待确认：影响执行的未明确条件；没有待确认内容时省略此项。

### 考试.md

每个独立事项使用一个 H2，例如 `## E-1571350-01：递推式答题提醒`。填写：

- 类型：考试安排、考试范围、答题要求、成绩组成、测验、考勤或其他考核。
- 现行要求：适用考试或考核、时间地点、形式、范围、题型、允许材料等已明确内容。
- 成绩关联：比例、分值、评分条件、加分或扣分规则，保留条件和适用范围。
- 确定程度：已明确、条件性提醒或待确认。
- 来源证据：每次相关提及的日期、节次、时间范围、逐字原话、讲义链接。
- 待确认：影响理解或执行的未明确条件；没有待确认内容时省略此项。

本课程尚未出现某类事项时，在对应文件说明“已核实课次中尚未发现明确事项”，同时保留已核实范围。

## 合并与持续维护

- 首次发现的事项使用 `A-<lesson_id>-<序号>` 或 `E-<lesson_id>-<序号>`，已有事项标识保持稳定。
- 根据事项对象和含义判断是否为同一要求。后续课次补充相同作业或考试安排时，更新原条目的现行要求并增加证据。
- 同一事项同一课次同一时间及原话已经存在时，直接复用。重新处理该课次时核对已有内容。
- 用户记录的已提交、已完成、得分等信息原样保留；教师布置任务的记录本身无法证明用户已经完成。
- 教师明确更新安排时，将现行要求及支持它的原话更新为当前有效内容。来源互相冲突且没有明确替代关系时，将有争议的字段标为待确认，并保留判断所需的两份证据。
- 一条通知同时涉及作业与成绩时，作业内容维护在 `作业.md`，成绩规则维护在 `考试.md`，通过事项标识相互引用。
- 两份文件只纳入已核实的课次；源资料缺失的课次单独标为尚未核实，并说明缺失资料。

## 验收

逐条核对本节讲义末尾与课程文件中的事项标识、时间、原话和要求。检查每次新提及是否已登记，引用是否能返回正确讲义，以及已有完成情况是否保留。核对期限、比例、分数和条件词，并确认一般课堂例子没有被登记为学生任务。
