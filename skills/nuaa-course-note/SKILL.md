# 课程讲义与考核事项

## 操作范围

用户的当前要求优先于本 skill。询问已有内容、完成情况或要求是否明确时，只读取资料并回答问题。生成、改写或维护请求按用户指定的课程和课次执行。

生成或改写讲义时，同时维护本节涉及的两份事项文件和章节索引。仅要求维护作业或考试记录时，完整核实指定课次的证据，并更新对应事项文件；讲义引用使用已存在的文件，尚无讲义时直接注明原始资料位置。仅要求维护章节索引时，核对相关课次及章节依据，更新索引文件。

以课程为单位维护以下文件：

| 位置 | 用途 |
| --- | --- |
| `课程/<课程名称>/讲义/YYYY-MM-DD 第N节.md` | 每个课次独立的一份讲义 |
| `课程/<课程名称>/作业&考试/作业.md` | 整门课程的作业与课后练习要求 |
| `课程/<课程名称>/作业&考试/考试.md` | 整门课程的考试、考核和成绩相关要求 |
| `课程/<课程名称>/复习/章节索引.md` | 各章及适量小节对应的课次、起止时间和讲义链接 |

生成课程内容时，首次建立该课程的三个子目录、两份事项文件和章节索引；已有目录继续使用。复习目录中本 skill 维护的文件为 `章节索引.md`，保留用户的其他复习资料。已有课程文件的迁移需要明确的迁移请求。

## 使用资料

- 定位课程、源资料和目标目录时，读取 [项目位置](references/project-context.md)。
- 编写讲义时，读取 [讲义设计](references/high-quality-note-standard.md)。
- 编写每节课末尾的事项或维护两份事项文件时，读取 [作业、考试与成绩记录](references/assessment-records.md)。
- 确定章节归属或维护复习目录的索引时，读取 [章节索引](references/chapter-index.md)。
- 源资料采用只读访问；讲义、事项和章节索引直接维护在本次确定的课程目录。

## 工作流程

1. **确定课程和课次。** 根据用户请求及真实 metadata 核对课程名称、课程标识、日期、节次和 `lesson_id`。按上课时间与节次排序。课程身份或课次范围存在影响结果的歧义时询问用户。
2. **确认资料可用。** 检查请求课次的 metadata、完整转写及时间信息。缺少课堂内容或可靠时间信息的课次立即停止生成，并说明缺少的具体资料；可以继续处理同一批次中资料完整的课次。
3. **阅读完整课堂内容。** 按时间顺序阅读每个目标课次的全部字幕或转写，包括开课前后的通知、课堂插话和结尾安排。工具输出被截断时继续读取尚未读取的部分。现有讲义用于保留用户内容和课程衔接。
4. **提取成绩相关证据。** 阅读时记录作业、考试、考核、考勤及加扣分等事项的完整原话与时间范围。完成全文阅读后，使用事项规范中的检索词复查；结合上下文判定每次提及的含义。
5. **编写讲义。** 请求涉及讲义时，按讲义设计组织充分的解释、例子和必要推导，为每个主要主题标注来源时间，准确区分各类重点。最后一个主要章节固定记录本节考试、作业与成绩事项。
6. **维护课程事项。** 将本节已核实的事项更新到 `作业.md`、`考试.md`。同一事项沿用已有标识并补充来源，保留用户填写的完成情况；需要交叉引用时使用课程内的相对 Markdown 链接。
7. **维护章节索引。** 请求涉及讲义或索引时，根据已核实的课程章节和教学时间，将本节内容补充到 `复习/章节索引.md`。记录每章的开始、结束及所涉及课次；章节跨课次、同一课次包含多章或后续再次讲解时，分别记录对应区间。有可靠依据且便于定位时补充主要小节。
8. **检查并完成。** 验证本次课次的正文、时间、引文、事项文件和章节索引之间的一致性。发现问题时直接修正并重新检查受影响部分。交付时提供本次更新文件的位置，并说明资料缺口或待确认事项。

## 完成条件

- 每个请求课次都有明确结果：已完成，或因具体资料缺失而未完成。完成数量按本次请求和真实资料计算。
- 正文覆盖该课次主要教学内容，解释与课程类型相符；重点标注能够说明依据。
- 每个主要主题的时间范围能够定位到源资料中的相关内容；时间以对应课次的媒体时间为准。
- 讲义末尾的每条考试、作业与成绩事项都有真实时间和原话，并出现在对应课程事项文件中；公开资料中的个人信息按事项规范省略引文，保留来源时间。
- 日期、比例、分数、题型、提交方式、截止要求和教师表述的确定程度均与来源一致；缺失信息明确标注。
- 两份事项文件中的新增条目能够返回来源讲义，重复处理同一课次不会重复增加事项。
- 章节索引能够定位各章在具体课次中的起止位置；跨课次区间、章节交接和后续补充有明确记录。未核实的章节边界与覆盖缺口明确标注，重复处理同一课次不会重复增加区间。
- 已有用户内容和完成情况得到保留。验收采用只读操作；发现问题时编辑受影响的目标文件并重新验收，写入范围以本次请求为准。
