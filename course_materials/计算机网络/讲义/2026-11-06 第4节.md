# 计算机网络｜2026-11-06 第4节

本节先介绍 MIME 如何扩展邮件格式以支持非 ASCII 内容与附件，随后讲评第四章作业的多道题，并按第一至第六章和第九章回顾考试范围。教师特别提醒计算题写清中间过程，区分适用条件、地址范围和路由匹配规则；不同章节复习深度不同，课堂口述的“了解”“会做”“重点”应分别对待。

## Web 邮箱与 SMTP 的协议分工（00:36–02:00）

使用浏览器访问邮件服务时，浏览器与用户所属邮件服务器之间通常通过 HTTP 交换页面和操作请求；发件服务器与收件服务器之间仍通过 SMTP 投递邮件。收件人用浏览器打开邮箱时，浏览器仍与邮箱网站通信。协议取决于通信双方和当前任务，不能仅凭“这是电子邮件”推断所有链路都用 SMTP（00:44–02:00）。

可以按消息路径逐段标注：

1. 用户在浏览器撰写邮件并提交给邮箱网站：浏览器与 Web 邮箱服务之间使用 HTTP。
2. 发件服务器向收件方邮件服务器投递：两台邮件服务器通过 SMTP 传递。
3. 收件人打开 Web 邮箱读取：浏览器与邮箱网站之间再次使用 HTTP。

若用户使用独立邮件客户端，客户端到服务器可根据配置使用 SMTP 提交邮件，并使用 POP3 或 IMAP 读取邮件。每段会话的应用协议不同，但一般都由各自的 TCP 连接承载。

## MIME 解决的邮件内容限制（02:05–03:40）

传统 SMTP 以 7 位 ASCII 文本为主要传输基础，直接发送任意二进制文件、非 ASCII 文字或某些长内容会遇到表示限制。MIME（Multipurpose Internet Mail Extensions，多用途 Internet 邮件扩展）为邮件首部和主体增加类型、编码及多部分内容的说明，使图片、音频、视频、附件和非英语文字能够通过邮件传送（02:05–03:36）。

MIME 扩展邮件格式，不取代 SMTP。发送端先依据 MIME 规则描述主体内容并把不适合直接传送的字节编码为可传输形式，再由 SMTP 传递；接收端读取 MIME 首部，按相应编码还原主体。这样应用层能表达多种内容，底层传输仍可使用原有 SMTP 会话。

MIME 常见首部字段包括：

| 字段 | 作用 |
| --- | --- |
| `MIME-Version` | 标明所使用的 MIME 版本 |
| `Content-Type` | 描述主体媒体类型和子类型，如 `text/plain`、`image/jpeg` |
| `Content-Transfer-Encoding` | 说明主体采用的传输编码，如 `base64` |
| `Content-ID` | 为主体中的某一部分提供标识 |
| `Content-Description` | 提供内容的文字说明 |

传统邮件首部与 MIME 首部共同描述邮件。若邮件带有附件，可查看原始邮件首部及 MIME 分隔结构，判断媒体类型、编码方式和附件名称；不要把编码后的字符当作附件的实际内容。

## 内容类型与传输编码（03:41–06:42）

`Content-Type` 告诉接收端主体内容是什么，媒体类型与子类型共同描述格式，例如 `text/plain`、`image/jpeg` 或音频类型。`Content-Transfer-Encoding` 则说明内容如何转换成传输可接受的字符。内容类型回答“这是什么”，传输编码回答“字节以什么形式传送”。

常见传输编码包括 `7bit`、`8bit`、`binary`、`quoted-printable` 和 `base64`。`7bit` 适用于符合 ASCII 限制的内容；`8bit` 可保留高位字节，但中间邮件系统未必都能按相同方式处理；`binary` 表示任意二进制数据，须有相应传送能力支持。`quoted-printable` 适合以 ASCII 为主、夹少量非 ASCII 字节的文本；`base64` 适合任意二进制数据，将字节编码为 ASCII 字符（04:34–05:58）。

Base64 编码把每 3 个字节，也就是 24 bit，分成 4 组，每组 6 bit，并把每个 6 bit 值映射为一个可打印字符。若原数据字节数不是 3 的倍数，末尾使用填充符号表示不足部分。编码后字符数量约为原始数据的 $4/3$，还需加上首部与格式开销。Base64 只改变表示形式，不提供加密，也不压缩数据。

`quoted-printable` 将少量非 ASCII 字节以可打印字符形式转义，适合正文以普通文本为主的邮件。Base64 适用于更多类型的字节序列，但会增加数据量。解码必须依据首部声明的编码方式；若把 Base64 文本误当作普通正文显示，用户看到的是编码串而非原始文件内容。

课堂说明 MIME 的编码细节不要求逐步计算，复习重点是理解为什么需要 MIME、它补充了什么信息，以及内容类型和传输编码的不同职责（06:00–06:42）。

## 第四章作业讲评：校验和、长度与前缀关系（07:21–12:49）

教师先讲评 IPv4 校验和题。按 16 进制分组计算时，应将首部按 16 bit 字分组，把各字相加并执行反码加法：若产生最高位进位，将进位回卷加到低 16 位；最后对和逐位取反得到校验和。验证收到的首部时，将全部 16 bit 字（含校验和）按同样方式相加，结果应为全 1（或其反码为 0，取决于题目采用的表示）。题目给出的字段应逐字核对，尤其不要将校验和字段和其他首部字段混淆（07:56–08:24）。

若 16 bit 字之和产生进位，例如和超过 `0xFFFF`，把超出的进位加回最低位继续计算。计算过程可以写成：

$$S=\operatorname{fold}_{16}\left(\sum_i w_i\right),\qquad C=\sim S$$

其中 $w_i$ 是各 16 bit 首部字，`fold16` 表示对每次 16 bit 溢出执行回卷进位，$C$ 为 16 bit 反码校验和。验证报文时需将所有字段连同 $C$ 纳入求和。若题目要求给过程，应保留每步的 16 进制加法、进位回卷和最终取反结果。

数据报长度字段包含 IP 首部和数据部分。题目若给出总长度和首部长度，IP 数据部分长度为 $L_{payload}=L_{total}-L_{header}$。教师指出作业题所给的是数据报长度，并给出了固定首部长度，因此要从总长度中减去首部长度，不能误把总长度当作数据部分长度（08:49–09:12）。

前缀匹配题需逐位比较网络前缀。某一地址若前 $n$ 位与路由表项一致，则该项是候选匹配；若多个表项都匹配，采用最长前缀匹配，即选择 $n$ 最大的表项。可以将 IPv4 地址转换为二进制，也可用十六进制分组辅助比较，但最终要确认被比较的位数正确（09:12–09:31；12:12–12:37）。

## 子网规划与地址集合不相交（09:50–12:00）

网络地址分配的关键不是只满足每个子网的主机数量，还要保证不同子网的地址块之间没有重叠。若已分配一个 `/24` 地址块，则其中所有地址都属于该块；之后再从其内部划分一个 `/25`，并把两者当作不同网络同时分配，会造成包含关系和地址冲突。正确做法是在父地址块内部规划互不重叠的子块，或把父块作为整体分配给单一网络（10:39–11:31）。

对需要至少 $H$ 台主机的 IPv4 子网，设主机位数为 $h$，常规子网需满足 $2^h-2\ge H$，其中网络地址和定向广播地址不能分配给普通主机。对应前缀长度为 $p=32-h$。点到点链路或题目另有特殊规定时，地址使用规则可能不同，应按题目条件处理。

VLSM 规划时先按主机需求从大到小排序，再为每个需求选取能容纳它的最小地址块；块大小必须是 2 的幂，并从符合块边界的位置开始分配。分配每个子网后，记录网络地址、前缀长度、可用主机范围和广播地址，再检查是否与其他子网交叠。若题目只要求至少若干主机，较大的地址块也可能满足要求，答案未必唯一；只要不重叠且地址总量允许即可（11:31–12:00）。

## 距离向量、BGP 与转发表作业讲评（12:52–23:33）

距离向量更新题中，路由器从邻居收到到某目的地的距离后，要加上到该邻居的链路代价，再与本地已有路径比较。若新路径距离更短，则更新下一跳和距离；若新旧距离相同，教师要求保持现有路径以避免不必要的变更（12:52–13:32）。因此，更新表格时不要对每条路由无条件重写，也不要把“到邻居的代价”重复相加。

$$D_x(y)=\min_{v\in N(x)}\{c(x,v)+D_v(y)\}$$

其中 $D_x(y)$ 表示路由器 $x$ 当前认为到目的地 $y$ 的最低代价，$N(x)$ 是邻居集合，$c(x,v)$ 是 $x$ 到邻居 $v$ 的链路代价。逐轮计算时先读取邻居通告，再加本地链路代价，最后更新最小值与下一跳。若候选值相等，依据本题课堂规则保留原表项。

路由协议题需要先判定问题问的是域内路由还是域间可达性。RIP、OSPF 属于 IGP，用于自治系统内部交换可达信息和计算路径；BGP 属于 EGP，用于自治系统之间交换可达前缀与路径属性。BGP 通告说明某个前缀可经由哪些自治系统到达，AS 内部的 IGP 再负责把分组送往相应边界路由器（13:44–14:53）。不能用“RIP/OSPF”回答题目所问的域间可达前缀来源。

转发表匹配题要逐项核对输入字段和动作。课堂讲评多播地址映射时，指出 IPv4 多播地址的高 4 bit 固定为 `1110`，余下 28 bit 中取低 23 bit 映射到以太网多播地址，因此多个 IP 多播地址可能映射到同一个 MAC 地址（41:50–42:32，第40节回顾）。映射存在多对一关系，网卡可能接收额外帧，再由 IP 层继续判断目标组地址。

SDN 流表题有多种等价表达方式。规则可逐一列出主机地址，也可用前缀或通配字段概括多个地址；关键是匹配集合与题目描述一致，动作对应正确端口或处理方式。教师指出此类题目的文字表达并不唯一，回答需保证覆盖要求的源地址、目的地址、输入端口和转发动作（20:17–23:33）。若题目明确要求图示，应按要求画出拓扑和规则关系，单纯文字可能无法呈现字段对应。

## 第一章：性能、体系结构与分层（23:33–24:50）

教师从网络性能指标开始复习，要求能理解指标含义并在给定条件下计算，不要求逐字背诵定义（24:09–24:22）。常见指标包括时延、吞吐量、带宽、丢包率和利用率。端到端时延可由处理、排队、传输和传播时延组成：

$$d_{nodal}=d_{proc}+d_{queue}+d_{trans}+d_{prop}$$

发送 $L$ bit 数据通过速率为 $R$ bit/s 的链路，传输时延为 $L/R$；距离为 $d$、传播速度为 $v$ 时，传播时延为 $d/v$。两者所表示的物理过程不同，不能将链路速率和信号传播速度混用。五层体系结构需要能够辨认各层名称及基本职责；课堂说明重点在理解层次关系（24:23–24:50）。

## 第二章：奈奎斯特、香农、信噪比与复用（24:50–28:21）

奈奎斯特准则用于无噪声带限信道的最高码元速率。若带宽为 $B$ Hz、每个码元可区分 $V$ 个离散电平，则理想最大数据率为：

$$R_{max}=2B\log_2 V$$

题目若给出二进制信号，$V=2$，故 $log_2 2=1$；若有 $M$ 种信号状态，则每个码元携带 $\log_2 M$ bit。奈奎斯特准则体现有限带宽对码元速率的限制，不包含噪声影响。

香农公式估算带宽为 $B$、信噪比为 $S/N$ 的噪声信道容量：

$$C=B\log_2\left(1+\frac{S}{N}\right)$$

若信噪比以分贝给出，应先换算为线性值：

$$\left(\frac{S}{N}\right)_{dB}=10\log_{10}\left(\frac{S}{N}\right),\qquad \frac{S}{N}=10^{(S/N)_{dB}/10}$$

例如 $30\,dB$ 对应线性信噪比 $10^{30/10}=1000$，代入香农公式时使用 1000，而不是 30（25:04–26:53）。考试计算要写出单位、线性转换和对数运算。奈奎斯特与香农适用条件不同：前者用于理想无噪声带限信道的码元速率上限，后者考虑噪声并给出理论容量上限。

复用技术通过共享信道资源承载多个通信流。频分复用分配不同频带，时分复用分配不同时隙，波分复用按光波长划分光纤信道；波长与频率满足 $c=\lambda f$，所以波分可理解为光通信中的频分。课堂要求知道各名称及其资源划分方式；多值数字传输相关作业若已经掌握其计算方法，可按题型练习（27:04–27:57）。PCM、T1/E1、SONET/SDH 以及宽带接入技术以基本概念了解为主（27:50–28:21）。

## 第三章：PPP、CRC、CSMA/CD 与以太网（28:21–39:35）

PPP 的帧定界有同步传输中的零比特填充和异步传输中的字节填充等方式。零比特填充用于避免数据内容中出现与帧边界相同的标志位模式；发送端在连续若干个 1 后插入 0，接收端按规则移除插入位。字节填充则对与标志或转义字符相同的字节加入转义处理，接收端恢复原字节。题目可能分别要求编码和解码，必须先辨别题目给的是发送前数据还是接收后的填充数据（28:21–29:30）。

CRC 题要能计算校验余数，也要判断接收帧是否正确。设数据多项式为 $M(x)$，生成多项式为 $G(x)$，其阶数为 $r$，发送端计算：

$$R(x)=\left[x^rM(x)\right]\bmod G(x),\qquad T(x)=x^rM(x)+R(x)$$

这里加法等价于模 2 加法，也就是逐位异或；$T(x)$ 可被 $G(x)$ 整除。接收端用相同生成多项式除收到的位串，余数为 0 表示未检测到错误，并不代表任意错误都必然被发现。列竖式时要按位对齐，使用生成多项式的非零项，避免把商位、被除数或补零位置写错（29:58–31:32）。

写出步骤有助于检查位对齐，也能呈现实际算法。计算发送校验位时，要将原数据后补 $r$ 个 0，再进行模 2 除法；检验收到的帧时，对完整接收位串直接除以生成多项式。两种操作目的不同，不能把“求发送余数”和“检验收到结果”互换。

CSMA/CD 的工作步骤是监听共享介质、空闲时发送、发送中继续检测碰撞；检测到碰撞后中止发送并退避，再尝试重新发送。以太网最小帧长与往返传播时延有关：发送端必须在最远冲突信号返回之前仍在发送，才能检测到碰撞。若链路传播距离增加或传输速率改变，题目可据此计算最小帧长；要先将往返传播时延换成 bit 数：

$$L_{min}\ge R\cdot 2\tau$$

其中 $R$ 为 bit/s，$\tau$ 为最远单程传播时延，$L_{min}$ 单位为 bit。具体题目可能另给中继器延迟或信号传播速度，需纳入往返时间（31:35–32:29）。

以太网帧格式不要求机械背诵，但应能识别目的 MAC、源 MAC、类型/长度、数据和 FCS 等字段的功能（32:30–33:01）。物理层中继器或集线器主要再生或扩展信号，不按目的 MAC 进行帧过滤；网桥和交换机在链路层学习源地址与端口对应关系，再决定登记、转发或丢弃。透明网桥通过源地址逆向学习形成转发表（33:23–35:08）。

VLAN 是交换机上的逻辑分组，同一物理局域网可分成不同广播域。主机到交换机的接入链路常传普通以太网帧；交换机之间的中继链路可带 IEEE 802.1Q VLAN 标记（35:11–36:04）。百兆以太网保留以太网 MAC 基本规则；千兆以太网的载波扩展保证必要的碰撞检测时间，帧突发允许一组帧连续发送以减少重复扩展的开销；万兆以太网采用全双工，不再使用 CSMA/CD（36:07–39:00）。PPPoE 知道其在以太网接入中承载 PPP 的概念即可（39:18–39:35）。

## 第四章：地址、前缀、路由与网络控制（39:40–43:55）

IPv4 地址分配、CIDR 地址块划分和前缀匹配是课堂明确要求的练习内容。分类地址也要能识别地址类别；IPv4 首部不要求默写，但要能阅读字段含义。路由选择依据目的地址匹配路由表项，多个表项匹配时采用最长前缀。VLSM 的子网范围须互不重叠，地址题要同时检查网络地址、广播地址、主机位数和地址块边界（39:40–40:17）。

IPv6 重点是地址表示、扩展首部的基本作用，以及双协议栈与隧道两种过渡机制。双协议栈主机同时运行 IPv4 和 IPv6；隧道把一种协议的分组封装在另一种协议分组中穿过不支持该协议的网络。二者解决过渡网络中的兼容问题，机制不同（40:22–40:44）。

RIP 使用距离向量算法；收到邻居的距离后加上本地链路代价，再比较并更新路由表。OSPF 使用链路状态信息，由路由器从自身为根计算到各目的网络的最低代价路径；课堂要求能画出小型拓扑中的最短路径树并计算代价。BGP 在自治系统之间交换前缀和路径属性，选择的是策略允许的路径，不一定是全网物理距离最短路径（40:44–41:49）。

多播 IPv4 到以太网 MAC 地址映射时，IPv4 多播地址前 4 bit 固定，剩余地址中有 23 bit 映射到 MAC 地址尾部，因此存在 32 个 IP 多播地址映射到同一 MAC 地址的可能。IGMP 用于主机与本地路由器之间报告加入或离开多播组，不负责建立不同网络之间的多播路由（41:50–42:48）。

VPN、NAT/NAPT、MPLS 和 SDN 的复习深度侧重基本机制：VPN 通过隧道等方式建立逻辑专用通信；NAT/NAPT 维护内部地址与外部地址/端口的映射；MPLS 依据标签和转发等价类转发；SDN 将控制逻辑集中于控制器，再向交换机下发流表。本节将这些主题列为基本概念了解，NAT/NAPT 的地址映射过程仍应能说明（42:50–43:55）。

## 第五章：端口、UDP/TCP 与可靠传输（43:55–48:44）

端口号为 16 bit，可表示 $0$ 至 $2^{16}-1=65535$ 的数值范围。课堂采用的划分将熟知端口用于常见公开服务，登记端口用于登记服务，动态端口主要用于客户端临时连接；答题时应依据课程采用的范围标准表述，区间边界以课件为准（44:01–44:45）。NAT/NAPT 可将多个内部主机的传输层连接映射到共享公网地址，端口号帮助区分不同会话。

TCP 是面向连接、可靠、面向字节流的运输层协议，提供有序字节交付和流量控制；UDP 无连接、面向报文，不保证可靠交付，但首部简单并可支持广播或多播。TCP 自行决定如何将字节流分段，接收端不保留应用写入边界；UDP 保留每个应用数据报的边界（44:47–45:51）。

TCP 连接管理需理解三次握手与连接释放，以及控制位对序号的影响。设客户端初始序号为 $x$、服务端为 $y$，SYN 各占一个序号，因此确认号分别为 $x+1$ 与 $y+1$。关闭连接时 FIN 同样占一个序号；双方可以分别结束发送方向，所以常见完整释放过程包含两次 FIN 与相应确认。第35节讲义列有过程和序号演算。

TCP 流量控制使用接收方通告的窗口限制未确认字节范围，窗口大小随接收缓存变化。发送端需要根据累计确认号、已发送数据和通告窗口判断下一批可发送字节；收到零窗口时暂停普通数据发送，并通过持续计时器定期探测窗口是否重新开放。窗口更新丢失时，探测机制可避免双方永久等待（46:15–46:58）。

拥塞控制处理网络路径承载能力。慢开始从较小拥塞窗口逐步探测容量；达到慢开始门限后进入拥塞避免；超时通常说明丢失较严重，发送端收缩窗口并重新进入较保守阶段；三次重复 ACK 可触发快重传，随后快恢复以减少从头开始的时间（46:59–48:44）。作答时应写明触发事件、窗口/门限变化方向及算法阶段，具体数值依据题目给出的 TCP 变体和规则计算。

## 第九章：无线局域网复习范围（48:45–49:30）

无线局域网的重点包括 IEEE 802.11 CSMA/CA 访问过程、随机退避与冻结、隐蔽站和暴露站、RTS/CTS 及持续时间字段。RTS/CTS 通过接收端响应向周边站点通告预约状态；其他站可依据持续时间更新 NAV。复习时还要能与以太网 CSMA/CD 对照：有线共享介质可在发送中检测碰撞，无线站点通常无法可靠完成发送中碰撞检测，所以采用冲突避免和接收确认（48:45–49:25）。

蜂窝移动网络与 Mobile IP 在课堂复习中不作为重点要求，可理解基本概念。此处的“无需特别关注”是教师对复习优先级的说明；无线局域网的上述机制仍属于明确要掌握的内容。

## 第六章：应用层复习范围（49:33–50:12）

应用层主要理解客户机/服务器、端口与常见协议的基本用途。教师特别提醒 DNS 与 HTTP 所用运输层协议不同：课堂范围中 DNS 使用 UDP，HTTP 使用 TCP（49:33–49:57）。结合第39节，应能区分 DNS 名称解析、HTTP Web 请求、SMTP 邮件投递、POP3/IMAP 邮件读取和 MIME 邮件内容扩展。
